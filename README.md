# scantronbot

Telegram-бот для мониторинга входящих переводов USDT (TRC20) на кошельки.
Транзакции отслеживаются через публичное API TronScan (https://tronscan.org/).
При каждом новом поступлении бот присылает уведомление с суммой и именем
отправителя — если для адреса отправителя заранее сохранена связка
"кошелек → имя".

## Возможности

- При первом запуске бот просит прислать адрес кошелька, за которым нужно
  наблюдать. Можно наблюдать сразу за несколькими кошельками.
- Кнопка **👛 Кошельки** — список отслеживаемых кошельков, добавление нового
  («➕ Добавить кошелек») и удаление («🗑 Удалить кошелек»).
- Кнопка **➕ Добавить** — связать адрес отправителя с именем (по этой связке
  в уведомлении вместо адреса будет показано имя): `+100 на Протон.`
- Если пришло поступление с неизвестного адреса, бот спрашивает
  `+<сумма> USDT от кого?` и ждёт имя — после ответа связка кошелек → имя
  сохраняется автоматически. В этом диалоге есть кнопка «❌ Отмена».
- Кнопка **📇 Контакты** — список связок кошелек → имя, с удалением
  («🗑 Удалить связку», по имени или по адресу); переименовать связку можно,
  просто заново добавив то же имя для того же адреса через «➕ Добавить».
- Кнопка **📒 Журнал** — последние 10 пополнений; в подменю кнопки «➕ Еще»
  (следующие 10), «📤 Экспорт» (CSV-файл со всей историей) и «⬅️ Назад».
- Кнопка **💰 Баланс** (или `/balance`) — текущий баланс USDT по каждому
  отслеживаемому кошельку.
- `/status` — диагностика: список кошельков, время последнего опроса
  TronScan, число неопознанных отправителей, связок и записей в журнале.
- Крупные поступления (`LARGE_DEPOSIT_THRESHOLD`) помечаются в уведомлении
  значком 🚨.
- Каждую полночь (по времени из `TIMEZONE`) бот: делает бэкап базы данных,
  присылает сводку за сутки (и за неделю — раз в 7 дней), а затем очищает
  переписку в чате — удаляет все сообщения за прошедшие сутки.
- Бот привязывается к первому пользователю, который его настроил (или к
  `OWNER_ID` из `.env`), и не даёт посторонним менять настройки.

## Развертывание на сервере (одна команда)

Требуется установленный Docker с плагином Compose.

```bash
cp .env.example .env   # укажите BOT_TOKEN, полученный у @BotFather
docker compose up -d --build
```

Это единственная команда, которая нужна для запуска бота на сервере. База
данных (кошельки, связки адрес → имя, журнал) сохраняется в папке `./data`
и переживает перезапуск контейнера; там же лежат ежедневные бэкапы
(`./data/backups`).

Обновление после изменения кода:

```bash
git pull
docker compose up -d --build
```

Остановка:

```bash
docker compose down
```

## Переменные окружения (`.env`)

| Переменная               | Обязательна | Описание                                                                    |
|---------------------------|-------------|------------------------------------------------------------------------------|
| `BOT_TOKEN`               | да          | Токен бота от @BotFather                                                     |
| `TRON_API_KEY`            | нет         | Ключ TronScan (https://tronscan.org/#/tools/api) — снимает лимиты на запросы |
| `OWNER_ID`                | нет         | Telegram user id единственного владельца бота (иначе — первый `/start`)      |
| `POLL_INTERVAL`           | нет         | Интервал проверки новых поступлений в секундах (по умолчанию 15)             |
| `TIMEZONE`                | нет         | Часовой пояс для полночной очистки/сводки, IANA-имя (по умолчанию `UTC`)     |
| `LARGE_DEPOSIT_THRESHOLD` | нет         | Сумма USDT, начиная с которой поступление помечается 🚨 (по умолчанию выкл.) |
| `BACKUP_DIR`              | нет         | Папка для бэкапов базы данных (по умолчанию `data/backups`)                  |
| `BACKUP_RETENTION_DAYS`   | нет         | Сколько дней хранить бэкапы (по умолчанию 14)                                |

## Использование

1. Откройте бота в Telegram и нажмите `/start`.
2. Пришлите адрес USDT TRC20 кошелька, за которым нужно наблюдать.
3. По кнопке **➕ Добавить** свяжите адреса отправителей с именами — тогда в
   уведомлениях о поступлениях будет показано имя вместо адреса.
4. По кнопке **👛 Кошельки** можно добавить ещё кошельки для наблюдения или
   удалить ненужные.

## Локальный запуск без Docker

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # укажите BOT_TOKEN
python -m bot.main
```
