# scantronbot

Telegram-бот для мониторинга входящих переводов USDT (TRC20) на заданный кошелек.
При каждом новом поступлении бот присылает уведомление с суммой и именем
отправителя — если для адреса отправителя заранее сохранена связка
"кошелек → имя".

## Возможности

- При первом запуске бот просит прислать адрес кошелька, за которым нужно наблюдать.
- Кнопка **👛 Кошелек** — посмотреть текущий кошелек и заменить его на другой.
- Кнопка **➕ Добавить** — связать адрес отправителя с именем (по этой связке
  в уведомлении вместо адреса будет показано имя).
- `/contacts` — показать список сохранённых связок.
- Уведомления о новых поступлениях приходят автоматически, без опроса вручную.
- Бот привязывается к первому пользователю, который его настроил (или к
  `OWNER_ID` из `.env`), и не даёт посторонним менять настройки.

## Развертывание на сервере (одна команда)

Требуется установленный Docker с плагином Compose.

```bash
cp .env.example .env   # укажите BOT_TOKEN, полученный у @BotFather
docker compose up -d --build
```

Это единственная команда, которая нужна для запуска бота на сервере. База
данных (кошелек для наблюдения и связки адрес → имя) сохраняется в папке
`./data` и переживает перезапуск контейнера.

Обновление после изменения кода:

```bash
git pull
docker compose up -d --build
```

Остановка:

```bash
docker compose down
```

## Переменные окружения (`.env`)

| Переменная      | Обязательна | Описание                                                                 |
|-----------------|-------------|---------------------------------------------------------------------------|
| `BOT_TOKEN`     | да          | Токен бота от @BotFather                                                  |
| `TRON_API_KEY`  | нет         | Ключ TronGrid (https://www.trongrid.io/) — снимает лимиты на запросы      |
| `OWNER_ID`      | нет         | Telegram user id единственного владельца бота (иначе — первый `/start`)   |
| `POLL_INTERVAL` | нет         | Интервал проверки новых поступлений в секундах (по умолчанию 15)          |

## Использование

1. Откройте бота в Telegram и нажмите `/start`.
2. Пришлите адрес USDT TRC20 кошелька, за которым нужно наблюдать.
3. По кнопке **➕ Добавить** свяжите адреса отправителей с именами — тогда в
   уведомлениях о поступлениях будет показано имя вместо адреса.
4. По кнопке **👛 Кошелек** можно в любой момент сменить наблюдаемый кошелек.

## Локальный запуск без Docker

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # укажите BOT_TOKEN
python -m bot.main
```
